Deva Construction Website

devaconstructions.in

The public face of the same construction business: a marketing site with a scroll-driven walkthrough hero and a project showcase the owner updates himself.

  • Built a frame pipeline that turns a rendered walkthrough into two WebP sequences (desktop and mobile) and scrubs them with scroll, so the hero plays like video without shipping one.
  • Project showcase reads published projects from Supabase behind row-level security, with an admin endpoint for adding new work and a proper empty state when nothing is live yet.
  • Contact form, services and about pages, sitemap and robots for search, and a custom domain with DNS and apex-to-www redirects set up on Vercel.
