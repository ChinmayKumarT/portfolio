AI Code Documentation System

code-doc-generator-gj97.onrender.com

An information-extraction pipeline that reads raw source files and writes the documentation a human would have skipped.

  • Parses source into structured entities (classes, functions, variables) through AST analysis, across multiple languages.
  • Transformer-based sequence models generate contextual natural-language summaries from the extracted structure.
  • Output as HTML, Markdown and PDF through a Flask interface.
